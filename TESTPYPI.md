# TestPyPI setup for Alexei
Use your individual TestPyPI account (separate from production; see [#84](https://github.com/hsluv/hsluv-python/issues/84)). Create GitHub environment `testpypi`, allow branch `main`, and optionally require approval. On **test.pypi.org**, configure a GitHub Trusted Publisher: owner `hsluv`, repository `hsluv-python`, workflow `testpypi.yml`, environment `testpypi`. Use the existing `hsluv` project's Publishing settings if you own it; otherwise register a pending publisher for that name if available. No API token is needed.
Merge this workflow, then run **Actions → Publish to TestPyPI → Run workflow** from `main`. It uploads the committed `hsluv.__version__`; if that version already exists on TestPyPI, change it before another upload. Inspect <https://test.pypi.org/project/hsluv/> and install the exact version in a clean environment with `python -m pip --isolated install --index-url https://test.pypi.org/simple/ --only-binary=:all: --no-deps "hsluv==VERSION"`. This workflow never uploads to production PyPI. See [PyPA's TestPyPI guide](https://packaging.python.org/en/latest/guides/using-testpypi/).
